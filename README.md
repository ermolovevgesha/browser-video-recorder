# Quick Start

## Установка зависимостей

```bash
pip install -r requirements.txt
playwright install chromium ffmpeg
```

Или через `uv`:

```bash
uv sync
uv run playwright install chromium ffmpeg
```

## Запуск

```bash
python capture_video.py
```

Или через `uv`:

```bash
uv run python capture_video.py
```
